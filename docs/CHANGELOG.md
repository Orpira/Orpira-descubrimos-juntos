# Cambios

## 0.1.0 · Revisión inicial

- Landing y catálogo con filtros combinables.
- Fichas ilustradas, pasos, favoritos, sellos y descarga para uso offline.
- Programa de ocho sesiones, planificador de grupos, documentación y pruebas locales.

## 0.2.0 · Preparación del piloto

- El planificador guarda y recupera un taller sin conexión, mostrando duración, materiales, precauciones y enlace a la ficha.
- La hoja del taller se imprime por separado. Privacidad permite borrar el taller guardado.
- Se añade un protocolo para validar una primera sesión sin registrar datos de participantes.
- El facilitador puede preparar un resumen imprimible de la evaluación agregada, incluso sin conexión. Si se indica una interrupción por seguridad, el resumen pide revisar y ensayar de nuevo la actividad.
- El planificador descarga la ficha del taller directamente y confirma dónde encontrarla sin conexión.
