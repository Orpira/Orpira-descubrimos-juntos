# Sistema visual

Papel cálido, tinta verde, paneles marfil y acento terracota. Georgia para títulos y tipografía del sistema para lectura. Las tarjetas usan ilustraciones originales en WebP y el texto identifica cada mundo. Los diseños CSS ajustan las columnas a 3, 2 y 1 según espacio. Los botones y campos principales usan 44 px de tamaño mínimo y anillo de foco visible.

Las fichas imprimibles conservan título, instrucciones, materiales, advertencias y QR cuando existe una URL pública. La impresión oculta controles interactivos.
