# Privacidad · borrador para revisión antes de lanzar

| Dato o recurso | Ubicación | Finalidad y salida |
| --- | --- | --- |
| IDs de fichas, pasos y sellos | localStorage del navegador | Pasaporte y pasos voluntarios. Borrado en Privacidad o ajustes del sitio. |
| Ficha y tamaño del taller | localStorage del navegador | Guardado voluntario. Se puede eliminar desde Comunidad o Privacidad. |
| Archivos de la aplicación | Cache Storage | Uso sin conexión y actualización. Fichas eliminables individualmente o desde Privacidad. |
| Solicitudes HTTP | Alojamiento por definir | Validar qué registros conserva el proveedor, base aplicable, acceso y plazos. |
| Exportación JSON | Equipo del usuario | Copia voluntaria bajo control de quien la descarga. |

Los datos locales anteriores no contienen nombres, edades elegidas, fotos ni perfiles. Los filtros viven en memoria. Solo se habilita narración con voz local en español.

Antes de publicar, completar aviso legal, política de privacidad, información del almacenamiento y condiciones con el responsable y proveedor reales. Revisar la aplicación del RGPD, LOPDGDD, LSSI y Ley 1581 de Colombia con asesoramiento competente. Verificar si cada almacenamiento responde al servicio explícitamente solicitado y reevaluar el consentimiento al añadir tecnologías opcionales.

Fuentes oficiales: [RGPD](https://eur-lex.europa.eu/eli/reg/2016/679/oj?locale=es), [LOPDGDD](https://www.boe.es/eli/es/lo/2018/12/05/3/con), [LSSI](https://www.boe.es/eli/es/l/2002/07/11/34/con), [AEPD](https://www.aepd.es/guias/guia-cookies.pdf), [Ley 1581](https://www.funcionpublica.gov.co/eva/gestornormativo/norma.php?i=49981).
