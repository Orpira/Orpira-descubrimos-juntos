# Contenido y publicación

Crear una entrada con slug estable, ilustración local, edad y grupo orientativos, nivel, duración, materiales, objetivos, misión, pasos, precauciones, accesibilidad, reflexión, variantes y referencias. Añadir una versión al cambiar los pasos de una ficha publicada para evitar restaurar marcas antiguas en instrucciones nuevas.

Estados: borrador, en revisión, aprobado, publicado y archivado. La versión de revisión muestra las fichas con ese estado. Para publicar, primero documentar la prueba física y la aprobación humana. Después registrar `revisada` como fecha ISO, cambiar `estado` a `publicado` y compilar en el entorno autorizado.

Referencias externas se usan para contextualizar conceptos. El texto y las ilustraciones del proyecto son originales. Revisar licencias si se incorpora una adaptación de terceros.
