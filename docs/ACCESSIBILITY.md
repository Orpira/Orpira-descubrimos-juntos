# Accesibilidad

Objetivo WCAG 2.2 AA. La interfaz tiene enlace para saltar al contenido, controles nativos etiquetados, foco visible, estructura de encabezados, avisos mediante regiones de estado y narrativa con alternativa escrita. Las imágenes decorativas tienen texto alternativo vacío.

Antes del piloto, verificar navegación completa por teclado, 200 % de zoom, contraste, VoiceOver y TalkBack, impresión a gran tamaño y adaptación de instrucciones con un facilitador. El resultado de Chromium no certifica conformidad.
