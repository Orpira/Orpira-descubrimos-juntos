# Reversión

Conservar el ZIP deployable anterior, su commit y la configuración de compilación. Ante una regresión, volver a servir el artefacto anterior sobre el mismo origen. Verificar que el worker detecta la versión restaurada. Cerrar todas las pestañas y reabrir para activar el cambio. Una ficha retirada por seguridad se mantiene fuera del catálogo aunque se restaure el código. Revisar descargas de fichas afectadas y comunicar el impacto al equipo piloto.
