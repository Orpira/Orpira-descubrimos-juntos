# Licencias y titularidad

El código, las fichas y las ilustraciones originales se entregan para el proyecto OrPiRa Social. La licencia pública de redistribución queda pendiente de decisión de su titular. Las dependencias npm conservan sus propias licencias, consultables desde los paquetes instalados y registrados en package-lock.json. El catálogo contiene referencias a fuentes externas, sin incorporar sus imágenes, textos ni archivos.
