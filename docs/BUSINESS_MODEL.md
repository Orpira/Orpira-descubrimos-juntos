# Modelo de sostenibilidad

El catálogo familiar, pasaporte, fichas y programa básico conservan el acceso gratuito. Validar uso repetido en talleres antes de explorar formación de facilitadores y colecciones especializadas. Medir el esfuerzo de adaptar una ficha, impartir una sesión y revisar seguridad contra la demanda observada.

La financiación futura puede proceder de servicios institucionales o patrocinios con reglas editoriales. El producto mantiene control de los contenidos y no comparte datos de menores con patrocinadores. El MVP no incorpora cobros ni publicidad.
